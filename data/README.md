# Dados

O corpus usado neste trabalho (publicações do X sobre a invasão das sedes dos Três Poderes em 8 de janeiro de 2023) foi cedido pelo CIBERDEM e é **confidencial**. Por isso, nenhum texto do corpus, identificador de usuário ou rótulo individual é publicado neste repositório.

Os scripts leem os dados a partir do diretório definido na variável `BASE_DIR` / `BASE` no início de cada arquivo; ajuste-a para o local onde os dados estiverem. Arquivos colocados nesta pasta não são versionados (ver `.gitignore`).
